# HTB Electrical & Air Conditioning website

Static website for HTB Electrical & Air Conditioning Pty Ltd.

## Making changes

The HTML pages are generated by `tools/build.py`. Edit the content in that
script (services, suburbs, reviews, page text), then rebuild from the
repository root:

```bash
python3 tools/build.py .
```

Styles are in `styles.css`, shared scripts in `site.js`, and photos in `images/`.
